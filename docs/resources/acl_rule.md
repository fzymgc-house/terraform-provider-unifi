# Acl Rule (Resource)

`unifi_acl_rule` manages a MAC ACL rule of the switches (Settings, Policy Table, MAC ACL). A switch evaluates the rules of a network in `acl_index` order where a frame enters it. The resource manages MAC rules only.

## Example Usage

```terraform
# Two MAC ACL rules hold one client to the gateway: the ALLOW rule admits its frames to the
# gateway and to broadcast, and the BLOCK rule drops every other frame from it. A switch
# evaluates the rules of a network in acl_index order.
#
# An empty source_macs is refused, because the controller reads it as every device.
# An empty switch_macs puts a rule on every switch.
resource "unifi_acl_rule" "allow" {
  name             = "client-to-gateway"
  action           = "ALLOW"
  acl_index        = 1
  network_id       = unifi_network.example.id
  switch_macs      = ["00:11:22:33:44:01"]
  source_macs      = ["02:00:00:00:00:10"]
  destination_macs = ["00:11:22:33:44:55", "ff:ff:ff:ff:ff:ff"]
}

resource "unifi_acl_rule" "block" {
  name             = "client-block"
  action           = "BLOCK"
  acl_index        = 2
  network_id       = unifi_network.example.id
  switch_macs      = ["00:11:22:33:44:01"]
  source_macs      = ["02:00:00:00:00:10"]
  destination_macs = []
}
```

## Schema

### Required

- `acl_index` (Number) The position of the rule. A switch evaluates a lower index first.
- `action` (String) `ALLOW` or `BLOCK`.
- `destination_macs` (Set of String) The destination MAC addresses that the rule matches. An empty set matches every device.
- `name` (String) The name of the ACL rule.
- `network_id` (String) The ID of the network that the rule applies to.
- `source_macs` (Set of String) The source MAC addresses that the rule matches. Must not be empty: the controller reads an empty source as every device, so a `BLOCK` rule would cut off the whole network.
- `switch_macs` (Set of String) The MAC addresses of the switches that enforce the rule. An empty set puts the rule on every switch.

### Optional

- `description` (String) The description of the ACL rule.
- `enabled` (Boolean) Whether the switches enforce the rule. Defaults to `true`.
- `site` (String) The name of the site of the ACL rule.
- `timeouts` (Attributes) (see [below for nested schema](#nestedatt--timeouts))

### Read-Only

- `id` (String) The ID of the ACL rule.

## Import

Import is supported using the following syntax:

The [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import) can be used, for example:

```shell
# ACL rules can be imported using the rule ID, or site:id for a non-default site.
terraform import unifi_acl_rule.example 6c0a2f1e-0000-4000-8000-000000000001

# For a non-default site, prefix the ID with the site name and a colon.
terraform import unifi_acl_rule.example default:6c0a2f1e-0000-4000-8000-000000000001
```
